## 静水2008 核心投资哲学

### 一句话说透

> **找到当下时代最景气行业核心受益且市场认可的α，回调分仓分批介入，对了死拿错了砍掉。**

### 只做极致，不做中庸

A股真正能让人赚大钱的只有两种公司：

1. **极致成长股** — 赛道景气度拉满，业绩处于极速爆发期，持续超预期
2. **极端低估价值股** — 身处行业周期底部，经过长期深度杀跌，估值处于历史绝对低位

### 选股四步法

1. **大势研判** — 仓位由大盘定（上升7成/震荡5成/下降3成以下）
2. **行业选择** — 只做主升浪中的行业，不碰下降通道的便宜货
3. **公司筛选** — 财务三关：扣非净利润正增长 + 现金流为正 + 环比往上走
4. **买卖时机** — 回调至支撑位分批建仓，基本面恶化或泡沫化时卖出
