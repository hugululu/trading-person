## 当前大势环境（2026年7月）

## 主线一：AI算力硬件链（极致成长·最高赔率）

### 赛道逻辑

全球科技巨头（微软/谷歌/亚马逊/Meta）持续大规模投入AI基础设施→中国供应商订单暴增→业绩兑现。**这不是讲故事，是订单多到要扩产的阶段。**

### 光模块 — 最肥的环节

#### 中际旭创（300308）

**最符合"极致成长"定义的标的。**

**为什么最强：**

| 指标 | 数据 |
|------|------|
| 2026H1归母净利 | 110-130亿（+175-225%） |
| 2026Q1归母净利 | 57.35亿（+262%） |
| 毛利率 | 46%（历史新高） |
| 1.6T出货占比 | Q1 28%→Q2预计34-36% |
| 硅光自研率 | >72%（成本比对手低20-30%） |
| 订单能见度 | 已签至2027年 |
| PE（2027E） | 约17倍 |

**核心壁垒**：英伟达GB300 1.6T独家主力供应商+硅光自研+毛利率46%碾压对手。

**关注要点**：
- 股价从591→1046，年内接近翻倍
- 适合"等回调"分批建仓，不宜追高
- PEG<0.5（极度低估），这是当前最重要的安全垫

---

#### 新易盛（300502）

行业第二，LPO技术路径卡位，亚马逊重要供应商。1.6T也在跟进，但NV认证尚未完全突破。**确定性低于中际旭创，弹性可能更大。**

---

### 存储芯片 — 弹性最大的环节

#### 兆易创新（603986）

存储芯片设计龙头，Q2环比+272%，在上游涨价中最受益。

**关键数据：**
- 2026H1归母净利：约69亿（+1099%）
- Q2约54.39亿，环比+272%
- 存储超级周期，DRAM/NAND价格持续上涨
- 长鑫科技IPO是潜在催化剂

**注意**：存储是强周期行业，涨得快跌得也快。需要设好止盈纪律。

#### 佰维存储（688525）、江波龙（688308）

模组厂，弹性大但质地弱于兆易。上游涨价挤压利润空间，环比增速已放缓。**不做首选。**

---

### AI服务器 — beta仓（跟踪）

#### 工业富联（601138）

- 2026H1归母234-244亿（+93-101%）
- AI服务器营收+230%
- 毛利率7.35%

**推理**：体量巨大、增速惊人、但利润薄。代工生意的本质决定了天花板。**赚的是行业景气钱（beta），不是超额收益（alpha）。** 如果已有仓位可持有，不建议在这个位置新建仓。

## 主线二：半导体设备（极致成长·最高确定性）

### 赛道逻辑

2026Q2 A股半导体设备公司出现了**历史上第一次"全员环比正增长"**——北方华创、中微公司、拓荆科技、盛美上海……全部环比增长，没有一个掉队。长期框架订单已锁定至2028年。

### 北方华创（002371）

平台型设备龙头，覆盖刻蚀+薄膜+热处理+湿法+离子注入全链条。

| 指标 | 数据 |
|------|------|
| 在手订单 | 820亿（+58%），覆盖2-2.5年交付 |
| 2026H1扣非 | Q2环比+46% |
| 营收规模 | 2025年393亿 |
| 毛利率 | 40.1% |
| 净利率 | 13.7%（被研发费用压制） |

**核心壁垒**：国产替代最纯正的标的，订单已锁至2028年，营收增长确定性极高。

**注意**：目前是"以利润换技术版图"阶段，赚的是营收扩张的钱，不是利润爆发的钱。**极致成色比中际旭创低一档。**

### 中微公司（688012）

CCP/ICP刻蚀双强，3D NAND存储刻蚀国内第一。

| 指标 | 数据 |
|------|------|
| Q2扣非 | 同比+115%，环比+51% |
| 在手订单 | 280亿+ |

### 拓荆科技（688072）

PECVD/ALD龙头，Q2营收环比+38%。

### 整体判断

半导体设备是确定性最高的方向，但利润释放较慢，而且北方华创的毛利率受研发拖累。**适合作为底仓配置，不适合做弹性攻击。**

### 小资金的核心原则（静水语录）

> "5万块不需要分散。分散是给大资金准备的。你需要的是确保那一只选对了，然后重仓它。"

1. **不买创业板/科创板** — 开不了就不用想，专注于主板找机会
2. **不买高价股** — 1手超过5千的都不考虑（否则买不了几手，失去了分批操作的空间）
3. **不追热门** — 已经涨到天上的票，你只有5万块去接盘，没有任何意义
4. **不止损就不要买** — 亏8%能接受吗？不能就别买
5. **留够子弹** — 永远留2-3万现金。大跌才有机会补仓

**一句话：** 5万块最正确的打法就是**极度集中、纪律严明、耐心等待**。选好标的，设好止损，然后坐着等。

### 通用止损纪律

- 任一标的亏损8% → 无条件离场
- 账户整体回撤超15% → 全面降仓至3成以下

### 通用止盈纪律

- 涨幅30%时 → 减持1/3仓位
- 涨幅50%时 → 减持至持仓的一半
- 剩下的让利润奔跑，但设好移动止损线在成本上方
